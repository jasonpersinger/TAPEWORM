Install

# per user, no root
tar -xzf tapeworm-v0.1.0-linux-x86_64-clap.tar.gz
cp tapeworm-v0.1.0-linux-x86_64-clap/tapeworm.clap ~/.clap/

tar -xzf tapeworm-v0.1.0-linux-x86_64-vst3.tar.gz
cp -r tapeworm-v0.1.0-linux-x86_64-vst3/tapeworm.vst3 ~/.vst3/

# verify first
sha256sum -c SHA256SUMS

Then rescan plug-ins. In REAPER: Preferences → Plug-ins → CLAP / VST → Re-scan.

Known Limits

  • No oversampling. Bright material at high Drive aliases. Up to 5 kHz at +12 dB, aliases stay near −60 dBc.
  • Azimuth combs in mono: first notch ≈ 2.8 kHz at 100 %, above 11 kHz at the default 25 %.
  • Random by design. Flutter jitter, dropouts and hiss keep running, so two renders in one session differ.
  • Linux only for now. Tested in REAPER.
