# Changelog

All notable changes to TAPEWORM are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] — unreleased (release candidate staged)

First public release.

### Added
* Cassette-tape effect for Linux x86_64 in CLAP and VST3 formats.
* Tape section: three tape types (Type I Ferric, Type II Chrome, Micro), Drive, Bias, Head Bump, Tape Age.
* Motor section: Wow, Flutter, Motor Bog, Pinch Bump, Azimuth Skew.
* Wear section: Generations (1–4), Dropouts, Tape Hiss, Ground Hum with 50 / 60 Hz selection.
* Spring reverb with Level, Decay, Damping and Pre-Tape / Post-Tape routing.
* Dry / Wet with a delay-matched dry path, Output Gain, 15 ms reported latency.
* Pixel-art editor.
* Portable release build (Debian 12 environment, glibc 2.35 or newer at run time), complete corresponding
  source archive with all dependency sources, third-party notices.
